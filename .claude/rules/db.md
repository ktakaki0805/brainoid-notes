# データベースを触るとき

- スキーマを変えたら、`pnpm db:generate` でマイグレーションを作り、同じコミットに入れる。
- 一度 `main` に入ったマイグレーションは書き換えない。直すときは、新しいマイグレーションを足す。
- SQLはDrizzleを通す。値を文字列でつないでSQLを作らない。
- 表を足す、列の意味を変える、というときは、`docs/design/data-model.md` の表も同じコミットで直す。
- タイトルの一意性は `(workspace_id, title)` の一意制約で守る。アプリの側の確認だけに頼らない。
- トークンは平文で保存しない。ハッシュだけを保存する。
