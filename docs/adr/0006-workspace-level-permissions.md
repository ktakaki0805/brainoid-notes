# ADR-0006: 権限はワークスペース単位、確認は can() に集約

- 状態：採用
- 日付：2026-11-13

## 状況

リンクでつながるグラフでは、ページ単位の権限はバックリンク、一覧、検索、エージェントの回答のすべてから漏れうる。ディレクトリ単位も検討したが、木があるとフォルダで整理したくなる。

## 決定

権限はワークスペース単位だけにする。役割は所有者、編集者、閲覧者。確認は `can()` に集約する。

## 理由

- ワークスペースの中では絞り込みが要らず、一覧が文字どおり「漏れなく」になる
- フォルダを作らない方針と合う
- `can()` の裏を差し替えれば、将来ページ単位にもできる

## 影響

- リンクも一覧もワークスペースをまたがない
- ワークスペースは「見せてはいけない相手がいるか」だけで分ける
- 権限エンジン（OpenFGA、SpiceDB）は入れない
