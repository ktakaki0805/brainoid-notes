# ADR-0004: データはPostgresだけに置く

- 状態：採用
- 日付：2026-11-13

## 状況

クラスの階層、バックリンク、全文検索、Yjsの状態を保存する場所が要る。

## 決定

すべてPostgresに置く。グラフDB、ベクトルDB、Redis、権限エンジンは入れない。日本語の全文検索にはPGroongaを使う。

## 理由

- 階層とバックリンクは再帰クエリで足りる
- 動かす部品が少ないほど、小さなチームで保てる
- 自前のサーバーで動かす版の道を残せる

## 影響

- 開発用のDBはPGroonga入りのイメージを使う
- 索引の表は、Yjsの状態から作り直せるようにする
- 必要になった部品は、その時点でADRを書いて足す
