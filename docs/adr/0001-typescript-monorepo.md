# ADR-0001: TypeScriptのモノレポにする

- 状態：採用
- 日付：2026-11-13

## 状況

エディタのノードとMarkdownの変換規則を、ブラウザとサーバーの両方で使う。往復テストを1つにしたい。

## 決定

すべてTypeScriptで書き、pnpmのワークスペースで1つのリポジトリにまとめる。

## 理由

- Lexicalをサーバーでheadlessで動かすには、サーバーもJavaScriptの実行環境が要る
- 共有するコードを `packages/` に置ける
- 小さなチームで言語を増やさない

## 影響

- サーバーもNode.js 22以降で動かす
- パッケージはソースのまま参照し、開発時はビルドしない
- 本番用のビルドはT-075で足す
