# ADR-0007: プロパティはワークスペースで一意、クラスもプロパティもページ

- 状態：採用
- 日付：2026-11-13

## 状況

複数のクラスや継承で、同じ名前のプロパティがぶつかったときの扱いを決める必要がある。frontmatterのキーは平らな名前で、RDFでもプロパティはクラスに属さない。

## 決定

プロパティはワークスペース内で名前が一意とし、プロパティ自身もページにする。クラスが宣言するのは「提案するプロパティ」で、強制しない。

## 理由

- 同じ名前は同じ意味、と決めれば衝突が起きない
- プロパティの定義をエージェントが読める
- Semantic Webの語彙に対応づけやすい

## 影響

- 提案されるプロパティは、全クラスと祖先の和集合になる
- 種類に合わない値は警告だけで、保存は通す
- 意味が違うなら名前を変える（`核 (線形代数)` と同じ規則）
