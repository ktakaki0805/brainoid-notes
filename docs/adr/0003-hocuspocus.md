# ADR-0003: 同期サーバーはHocuspocusを自分たちで動かす

- 状態：採用
- 日付：2026-11-13

## 状況

Yjsの同期サーバーが要る。接続時に権限を確かめ、保存のたびに索引を更新し、サーバー側からも文書を書きたい。

## 決定

Hocuspocus v4を自分たちで動かす。

## 理由

- 認証、読み込み、保存のフックがある
- サーバー側から文書に直接つなげる
- 研究データを自分たちのDBに置ける

## 影響

- Node.js 22以降が必要
- 最初は1台で動かす。複数台にするときはRedisが要る
- ホスト型の同期サービスは使わない
