# ADR-0008: エージェントの既定は提案、製品からAIにデータを送らない

- 状態：採用
- 日付：2026-11-13

## 状況

研究の記録に、AIの知識由来の値を黙って混ぜたくない。未発表の結果や企業の機密も入る。

## 決定

トークンの既定の権限は「提案」にする。直接書き込みは、所有者が許可したトークンだけ。本文の書き換えは、どの権限でも行わない。製品のサーバーからAIのAPIは呼ばない。

## 理由

- 人が承認したものだけが事実になる、という線を保てる
- どのAIに何を渡すかを、所有者が決められる
- AIの費用を製品が持たなくて済む

## 影響

- アプリ内のAIはv1では作らない
- 提案の置き場は1つで、外部のエージェントが同じ口から書く
- 編集とアクセスをサーバー側で記録する
