## 目的

いまのObsidianのノートを、frontmatterつきのMarkdownから取り込めるようにする。

## 参照

- [Markdownの形式](../design/markdown-format.md)

## やること

- 複数のMarkdownファイル（またはzip）を受け取るAPI
- タイトル、frontmatter、本文を読み、ページとYjsの文書を作る
- 取り込みの中でリンクを解決し、残りは「まだないページ」へのリンクにする
- タイトルがすでにあるときの扱い（既定は、飛ばす）
- 取り込めなかった記法やファイルの一覧を返す
- 画面の入口

## やらないこと

- Obsidianに固有の記法の網羅（埋め込み、タグなど）。何が落ちたかを見せることを優先する

## 受け入れ条件

- [ ] 書き出したzipを別のワークスペースに取り込むと、同じ内容になる
- [ ] 取り込みで落ちたものが、一覧で分かる
- [ ] 途中で失敗しても、半端なページが残らない

## 未決事項

- 使えない記法（表、画像）を落とすか、文字のまま残すか
