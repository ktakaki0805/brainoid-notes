## 目的

所有者が、トークンを発行し、失効できるようにする。

## 参照

- [エージェント連携](../design/mcp.md)
- [権限、トークン、AI](../design/security.md)
- [APIと権限](../design/api.md)

## やること

- `agent_tokens` の表
- 発行（平文は1回だけ返す。DBにはハッシュ）、一覧、失効のAPI
- 権限は、読み取り、提案、直接書き込み。既定は提案
- トークンでの認証のミドルウェアと、`can()` へのつなぎ込み
- ワークスペースの「エージェント接続を止める」スイッチ

## やらないこと

- MCPのツール（T-037）
- 設定の画面（T-064）
- 回数の上限（T-073）

## 受け入れ条件

- [ ] 所有者以外は、発行も失効もできない
- [ ] 失効したトークンは401になる
- [ ] スイッチを切ると、どのトークンも使えない
- [ ] DBに平文のトークンがない
