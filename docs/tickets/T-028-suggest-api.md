## 目的

リンクの入力候補と、検索バーのタイトル検索に使うAPIを作る。

## 参照

- [APIと権限](../design/api.md)
- [画面](../design/ui.md)

## やること

- タイトルと別名の部分一致で、候補を返す
- 型（クラスの名前）を一緒に返す
- 並びを決める（前方一致を先に、最近更新したものを先に）
- 件数の上限

## やらないこと

- 本文の検索（T-049）
- 「書いているページの型に合うものを先頭に」の並べ替え（T-029）

## 受け入れ条件

- [ ] 別名で引ける
- [ ] 候補に型の名前が付く。型のないページは、そうと分かる形で返る
- [ ] 1000ページあっても遅くならないことを確かめてある
