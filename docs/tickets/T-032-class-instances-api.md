## 目的

クラスのインスタンスを、下位クラスの分も含めて漏れなく返す。

## 参照

- [APIと権限](../design/api.md)
- [データモデル](../design/data-model.md)

## やること

- 子孫のクラスをたどる再帰クエリ
- インスタンス一覧のAPI（ページ送りつき、件数つき）
- 各インスタンスについて、どの下位クラス経由かと、主なプロパティを返す
- クラス一覧のAPI（件数と、提案するプロパティ）

## やらないこと

- 画面（T-033、T-062）
- 未確認の候補の件数（T-045）

## 受け入れ条件

- [ ] 下位クラスのインスタンスが、親クラスの一覧に出る
- [ ] 3段の継承でも出る
- [ ] 件数と、一覧の中身が一致する
- [ ] `subclass_of` が循環していても、エラーにならない
