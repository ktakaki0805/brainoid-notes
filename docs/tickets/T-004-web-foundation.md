## 目的

画面を足していける枠を作る。サイドバーと本文の2カラム、ルーティング、APIの呼び方をそろえる。

## 参照

- [画面](../design/ui.md)
- [コードとテストの書き方](../dev/conventions.md)

## やること

- ルーティングを入れる（ライブラリを選び、理由をコミットメッセージに書く）。`LinkProvider` につなぎ、Astryxの部品のリンクがルーターを通るようにする
- 画面の枠を、Astryxの `AppShell` と `SideNav` で作る。`pnpm astryx build` でテンプレートを選ぶところから始める
- 狭い画面でのサイドバーの扱いは、Astryxの部品の動きに従う
- APIを呼ぶ薄い関数と、エラーの表示
- 確認用の画面（`App.tsx`）を置き換える

## やらないこと

- 各画面の中身（T-027以降）
- サイドバーの最近のページ（T-065）
- テーマの作り直し（色を足す必要が出たら、その画面のチケットで足す）

## 受け入れ条件

- [ ] `/` と、存在しないパスの表示がある
- [ ] 画面の幅を狭めても、サイドバーの項目に届く
- [ ] 色、余白、文字の大きさを直書きしていない（Astryxの部品のpropsと、トークンだけで決めている）
- [ ] キーボードだけですべての部品に届き、フォーカスが見える
- [ ] `pnpm astryx doctor` に失敗（fail）がない
