## 目的

許可されたトークンが、プロパティを書き、ページを作れるようにする。

## 参照

- [エージェント連携](../design/mcp.md)
- [共同編集と保存](../design/sync.md)

## やること

- `set_property`、`create_page` を実装する
- 直接書き込みの権限を確かめる
- 書いたトークンを、編集の記録に残す
- 作成時にタイトルが重なったら、それと分かる返事を返す

## やらないこと

- 本文への追記（T-048）

## 受け入れ条件

- [ ] 直接書き込みのトークンだけが呼べる
- [ ] 書いた内容が、開いている人の画面にすぐ出る
- [ ] 編集の記録に、エージェントとトークンの名前が残る
