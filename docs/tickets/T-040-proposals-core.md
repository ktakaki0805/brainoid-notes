## 目的

提案を置き、承認と却下を、記録つきで行えるようにする。

## 参照

- [型付けと提案](../design/proposals.md)
- [データモデル](../design/data-model.md)
- [共同編集と保存](../design/sync.md)

## やること

- `proposals` マップを読み書きする部品と、`proposals` の表
- 承認のAPI（`props` に書き、`proposals` から消す。提案者と承認者を記録する）
- 却下のAPI（同じ提案を二度と受け付けない印を残す）
- APIサーバーから同期サーバーの文書を書く方法を決めて、`sync.md` に書く
- 保存時に、未承認の提案を索引に入れる

## やらないこと

- 画面（T-041）
- MCPからの提案（T-043）

## 受け入れ条件

- [ ] 承認すると、開いている人の画面のプロパティにすぐ出る
- [ ] 却下した提案と同じものは、もう置けない
- [ ] 閲覧者は、承認も却下もできない
- [ ] 未承認の提案は、書き出したMarkdownに出ない
