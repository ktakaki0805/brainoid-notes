## 目的

クラスを、件数と提案するプロパティつきで一覧する。

## 参照

- [画面](../design/ui.md)

## やること

- クラス一覧の画面（下位クラスは、親の下に字下げする）
- 件数は、下位クラスを含む
- 型のないページの件数と、ページ一覧への入口

## やらないこと

- クラスの作成や並べ替えの専用の画面（クラスも普通のページとして作る）

## 受け入れ条件

- [ ] 下位クラスが、親の下に出る
- [ ] 複数の親を持つクラスの出し方が決まっていて、文書に書いてある
- [ ] 件数が、インスタンス一覧と一致する
