## 目的

タイトルの一意性を守りながら、ページを作り、名前を変え、消せるようにする。

## 参照

- [APIと権限](../design/api.md)
- [データモデル](../design/data-model.md)
- [共同編集と保存](../design/sync.md)

## やること

- 作成、改名、削除、タイトルから引くAPI
- タイトルが重なったら409を返す
- タイトルの正規化（前後の空白など）の規則を決める
- 削除のしかた（すぐ消すか、印を付けるか）を決めて `security.md` に書く

## やらないこと

- 本文とプロパティの編集（同期サーバーを通る）
- 画面（T-027）

## 受け入れ条件

- [ ] 同じタイトルで2回作ると、2回目が409になる
- [ ] 改名しても、ページIDと、そこへのリンクは変わらない
- [ ] 閲覧者は、作成、改名、削除ができない
- [ ] 同時に同じタイトルで作っても、できるのは1つだけ
