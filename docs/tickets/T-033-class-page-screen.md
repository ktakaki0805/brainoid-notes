## 目的

クラスのページにインスタンス一覧を、プロパティのページに使用箇所を出す。未入力のプロパティも見えるようにする。

## 参照

- [画面](../design/ui.md)
- [データモデル](../design/data-model.md)

## やること

- クラスページの下に、インスタンス一覧（下位クラス経由の印つき）
- プロパティのページの下に、そのプロパティを使っているページの一覧
- インフォボックスに「未入力」の行（クラスから提案されているが、値のないプロパティ）
- クラスのページであることを、題の横に示す

## やらないこと

- 未確認の候補と、型のないページの件数（T-045）

## 受け入れ条件

- [ ] 型を付けると、そのクラスが提案するプロパティが「未入力」に出る
- [ ] 複数の型を付けると、提案が和集合になる
- [ ] インスタンスを足したあと、一覧を新しくする手段がある
