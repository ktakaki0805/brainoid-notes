# 画面

画面の構成と動きの基準は、UIプロトタイプです。部品、余白、色の体系は、デザインシステムの [Astryx](https://github.com/meta/astryx) に従います（[ADR-0011](../adr/0011-astryx-design-system.md)）。

- UIプロトタイプ：https://claude.ai/artifact/7Hr4U6GEUPyo844wRyERU3 （作成者が共有するまで、ほかの人は開けません）
- Astryxの文書：手元で `pnpm astryx docs`、部品は `pnpm astryx component <名前>`

プロトタイプは架空のデータで動く見本で、Astryxを使っていません。「何がどこにあり、どう動くか」をプロトタイプで確かめ、「どの部品で、どんな見た目にするか」はAstryxで決めます。見た目が食い違ったら、Astryxに合わせます。

本文のエディタは、プロトタイプではブラウザの編集機能で真似たものです。実装ではLexicalで作り直します。

## 部品の対応（案）

どの画面にAstryxのどの部品を使うかの案です。各チケットで `pnpm astryx component <名前>` を読んで確かめ、合わなければ別の部品にしてかまいません。変えたら、この表を直します。

| 画面の要素                       | Astryxの部品                                               |
| -------------------------------- | ---------------------------------------------------------- |
| 画面の枠、サイドバー             | `AppShell`、`SideNav`、`SideNavItem`、`SideNavSection`     |
| ページのタイトル、見出し、文     | `Heading`、`Text`                                          |
| 「ページ」と「Markdown」の切替   | `SegmentedControl`                                         |
| Markdownの表示                   | `CodeBlock`                                                |
| インフォボックス                 | `MetadataList`、`MetadataListItem`。値のリンクは `Token`   |
| 提案の行                         | `warning` のトークンの行に、`Button`（承認、却下）         |
| バックリンク、インスタンス一覧   | `List`、`ListItem`。列が要るなら `Table`                   |
| ページ一覧                       | `Grid` に `ClickableCard`。切り替えは `SegmentedControl`   |
| クラス一覧                       | `TreeList`                                                 |
| 検索                             | `CommandPalette`                                           |
| リンクの候補（エディタの中）     | `Typeahead` 系か `Popover`（T-029で確かめる）              |
| 設定のメンバー、トークン、記録   | `Table`、`Selector`、`Switch`、`Timestamp`、`Dialog`       |
| 編集中のほかの人                 | `AvatarGroup`                                              |
| 確認、知らせ、空の状態           | `AlertDialog`、`Toast`、`EmptyState`                       |

Astryxは「細かいデータの並びは、カードではなく行にする」ことを勧めています。ページ一覧は、Scrapboxのように眺めて選ぶ画面なのでカードにします。インスタンス一覧やバックリンクは、行にします。

## エディタの動き

| 動き            | 内容                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| 直接編集        | 本文をクリックするとそのまま打てる。Enterで段落が分かれる                                |
| リンクの候補    | `[[` と打つと、カーソルの位置に候補が出る。上下キーで選び、EnterかTabで確定、Escで閉じる |
| 候補の並び      | 書いているページの型に合うものを先頭に出す。型と別名を表示する                           |
| 表示名          | `核 (線形代数)` を選ぶと、本文には「核」と表示する                                       |
| その場で変換    | `[[名前]]` と自分で閉じてもリンクになる                                                  |
| リンクは1つの塊 | カーソルは中に入らず、Backspaceで丸ごと消える。クリックでそのページへ移る                |
| まだないページ  | 破線の下線と別の色で表示する。クリックするとその名前でページができる                     |
| 日本語入力      | 変換中のEnterで候補を確定しない                                                          |

エディタを、Astryxのリッチテキスト部品（`@astryxdesign/richtext`）の上に作るか、自前で組むかは未決です。T-015で決めます。どちらでも、本文の見た目はAstryxのトークンで決めます。

## インフォボックス

- 上から、`type`、予約語、利用者のプロパティ、提案、未入力の順に並べる。
- 予約語は等幅の書体、利用者のプロパティ名はプロパティのページへのリンクにする。
- 提案は、注意の色（`warning`）の行にする。この色は提案にだけ使う。
- 提案されているが値のないプロパティは「未入力」の1行にまとめる。

## 検索

- サイドバーの「検索」で開く。背景のクリックかEscで閉じる。
- 何も打たないうちは最近のページを出す。打つと、タイトル、別名、本文の順に一致したものを出す。
- 上下キーで選び、Enterで開く。一致するタイトルがなければ、その名前で新しく作れる。
- キーボードのショートカット（⌘Kなど）は、実装で足す。プロトタイプにはない。

## 見た目

見た目は、Brainoidのテーマで決めます。Astryxの neutral テーマを土台に、アクセント色と書体だけを変えたものです。

| 項目                     | 内容                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------- |
| テーマの定義             | `apps/web/src/themes/brainoid/brainoidTheme.ts`                                        |
| アクセント色             | プロトタイプの深緑（`#0B6E5F`）から作ったパレット。リンク、主ボタン、選択中に使う      |
| 書体                     | IBM Plex Sans JP。コードと予約語は IBM Plex Mono。`brainoid.fonts.css` で読み込む      |
| 余白、角丸、文字の大きさ | neutral のまま                                                                         |
| 状態の色                 | neutral のまま（`success`、`warning`、`error`、`info`）                                |
| ロゴ                     | `apps/web/public/logo.png`                                                             |

用途ごとの色は、次のトークンを使います。

| 用途                   | トークン                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------- |
| リンク、主ボタン       | `--color-accent`、`--color-text-accent`                                            |
| 提案（未承認）         | `--color-warning-muted` の地、`--color-on-warning-muted` の文字、破線の枠          |
| 根拠のハイライト       | `--color-warning-muted`                                                            |
| まだないページのリンク | 案：`--color-text-secondary` と破線の下線。提案と同じ色にはしない（T-010で決める） |

テーマを変えるときは、次の順で進めます。

1. `brainoidTheme.ts` を直す。色を足すときは、パレット（`palette.config.json`）から作るか、[ライト, ダーク] の組で書く。
2. `pnpm theme:build` で生成物を作り直す。
3. 生成物（`brainoid.css`、`brainoid.js`、`*.d.ts`）も一緒にコミットする。ずれていると `pnpm check` が落ちる。

### 未決のこと

| 項目         | いまの状態                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------ |
| ダークモード | v1では出さず、ライトに固定している（`main.tsx`）。テーマにはダークの値も入っている               |
| 書体の配り方 | Google Fontsから読み込んでいる。自分たちで配るかどうかは、デプロイ（T-075）までに決める          |
| 文字の大きさ | neutral の14pxを基準にしている。プロトタイプは15pxだった。日本語で小さいと感じたら、テーマで直す |

## 使いやすさの決まり

- 部品はAstryxから選ぶ。キーボード操作、フォーカス、読み上げは部品に入っているので、作り直さない。
- 押せるものの大きさは、部品の既定に従う。自分で高さを決めない。
- 色だけで区別しない（提案は破線の枠と「提案」の文字、状態は文字のラベルも添える）。
- 文字と地の色の比は4.5対1以上にする。Astryxのトークンの組（`--color-warning-muted` と `--color-on-warning-muted` など）を崩さずに使えば満たせる。
- 狭い画面でのサイドバーの扱いは、`AppShell` の動きに従う。

## 対応ブラウザ

Baseline 2026です（Chrome 125以降、Edge 125以降、Safari 26以降、Firefox 147以降）。Astryxの重なる部品（メニュー、候補、ツールチップ）が、CSS anchor positioningを使うためです。理由と、広げるときの手順は [ADR-0012](../adr/0012-modern-web-guidance-and-baseline.md) にあります。

## プロトタイプと実装の違い

| プロトタイプ                                 | 実装                                              |
| -------------------------------------------- | ------------------------------------------------- |
| 部品も色も、その場で作ったもの               | Astryxの部品と、Brainoidのテーマ                  |
| 提案は琥珀色、まだないページは茶色           | 提案は `warning` のトークン。まだないページは未決 |
| 押せるものは高さ44px以上                     | 部品の既定の大きさ                                |
| 狭い画面では、サイドバーを本文の下に回す     | `AppShell` の動きに従う                           |
| 本文の外をクリックした時点で保存             | 打つたびに同期する                                |
| リンクに変換すると「元に戻す」の履歴が切れる | 履歴は切れない（Yjsの取り消しを使う）             |
| ほかの人のカーソルは出ない                   | 出す（T-066）                                     |
| 段落とリンクだけ                             | 見出し、箇条書き、引用、太字、斜体も使える        |
