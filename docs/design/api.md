# APIと権限

APIサーバー（Hono）は、ログイン、メンバー管理、ページの作成と改名、一覧と検索、取り込みと書き出し、MCPを受け持ちます。本文とプロパティの編集はここを通らず、同期サーバーを通ります。

権限の考え方は決定済みです。エンドポイントの一覧は案で、各チケットで確定します。

## 権限

権限はワークスペース単位だけです。ワークスペースの中は、メンバー全員にすべてのページが見えます。

| できること                             | 所有者 | 編集者   | 閲覧者   |
| -------------------------------------- | ------ | -------- | -------- |
| ページを読む、検索する、書き出す       | できる | できる   | できる   |
| ページを作る、編集する、改名する、消す | できる | できる   | できない |
| 提案を承認する、却下する               | できる | できる   | できない |
| メンバーと役割を変える                 | できる | できない | できない |
| トークンを発行する、失効させる         | できる | できない | できない |
| エージェント接続を止める               | できる | できない | できない |

権限の確認は、必ず次の関数を通します（T-022）。ルートの中で役割を直接比べません。

```ts
can(actor, action, resource): boolean
```

- `actor` は人（ユーザーと役割）か、エージェント（トークンと権限）。
- 将来ページ単位の共有が必要になったら、この関数の裏を差し替える。

## 認証

| 相手         | 方法                                | 状態                      |
| ------------ | ----------------------------------- | ------------------------- |
| 人           | セッション（Cookie）                | 方式は未決。T-021で決める |
| エージェント | トークン（`Authorization: Bearer`） | T-036                     |

トークンは発行時に1回だけ表示し、DBにはハッシュだけを保存します。

## 決まりごと

- リクエストとレスポンスはJSON。入力はzodで検証する。
- エラーは `{ "error": { "code": "...", "message": "..." } }` の形にそろえる（T-003）。
- 一覧は、ワークスペースの中では誰に対しても同じ結果を返す。人によって絞り込まない。
- 承認前の提案を返すときは、事実と区別できる形（`status: "pending"`）で返す。

## エンドポイント（案）

| メソッドとパス                              | すること                                     | チケット |
| ------------------------------------------- | -------------------------------------------- | -------- |
| `GET /health`                               | 生存確認                                     | ひな型   |
| `GET /me`                                   | ログイン中の人と、入っているワークスペース   | T-021    |
| `GET /workspaces/:ws/members` ほか          | メンバーの一覧、追加、役割の変更、削除       | T-022    |
| `POST /workspaces/:ws/pages`                | ページを作る。タイトルが重なれば409          | T-024    |
| `PATCH /workspaces/:ws/pages/:id`           | 改名する                                     | T-024    |
| `DELETE /workspaces/:ws/pages/:id`          | 消す                                         | T-024    |
| `GET /workspaces/:ws/pages/by-title/:title` | タイトルからページを引く                     | T-024    |
| `GET /workspaces/:ws/pages`                 | ページ一覧（絞り込み：すべて、型なし、定義） | T-061    |
| `GET /workspaces/:ws/pages/suggest?q=`      | リンクの候補。タイトルと別名で引く           | T-028    |
| `GET /workspaces/:ws/pages/:id/backlinks`   | バックリンク。プロパティ名ごとにまとめる     | T-034    |
| `GET /workspaces/:ws/classes`               | クラス一覧                                   | T-062    |
| `GET /workspaces/:ws/classes/:id/instances` | インスタンス一覧（下位クラスを含む）         | T-032    |
| `GET /workspaces/:ws/pages/:id/markdown`    | 1ページを書き出す                            | T-035    |
| `GET /workspaces/:ws/export`                | 全ページをzipで書き出す                      | T-035    |
| `POST /workspaces/:ws/import`               | Markdownを取り込む                           | T-060    |
| `GET /workspaces/:ws/search?q=`             | 全文検索                                     | T-049    |
| `POST /proposals/:id/approve`、`/reject`    | 提案を承認、却下する                         | T-040    |
| `GET/POST/DELETE /workspaces/:ws/tokens`    | トークンの一覧、発行、失効                   | T-036    |
| `/mcp`                                      | MCP（[mcp.md](mcp.md)）                      | T-037    |

Webからは `/api` を付けて呼びます（開発時はViteのプロキシがAPIサーバーへ回します）。
