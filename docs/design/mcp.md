# エージェント連携（MCP）

アプリ内のチャットAIは作らず、外部のエージェント向けの口を優先します。エージェントはトークンでつなぎ、MCPのツールで読み書きします。

トークンの権限と、書けるものの範囲は決定済みです。ツールの名前と引数は案で、T-037以降で確定します。

## トークンの権限

| 権限         | できること                                                         |
| ------------ | ------------------------------------------------------------------ |
| 読み取り     | ページの取得、型での列挙（下位クラスを含む）、リンクの探索、検索   |
| 提案（既定） | 読み取りに加えて、型とプロパティの提案を書く                       |
| 直接書き込み | 提案に加えて、プロパティの書き込み、ページの新規作成、本文への追記 |

- トークンを発行できるのは所有者だけで、いつでも失効できる。範囲はワークスペース単位。
- 既定は「提案」。直接書き込みは、所有者が許可したトークンだけに与える。
- 本文の書き換えは、どの権限でも行わない。同時に編集している人の入力を潰すため。
- 所有者は、ワークスペースごとにエージェント接続を丸ごと止められる。

## ツール（案）

| ツール               | 権限         | すること                                                             | チケット |
| -------------------- | ------------ | -------------------------------------------------------------------- | -------- |
| `get_page`           | 読み取り     | タイトルかIDで1ページを返す。Markdown、プロパティ、未承認の提案      | T-037    |
| `list_pages_by_type` | 読み取り     | クラスのインスタンスを漏れなく返す。下位クラスを含む                 | T-037    |
| `list_classes`       | 読み取り     | クラスと、提案するプロパティ、件数を返す                             | T-037    |
| `get_links`          | 読み取り     | あるページから出るリンクと、入ってくるリンクを返す。プロパティ名つき | T-037    |
| `search_pages`       | 読み取り     | タイトル、別名、本文から探す                                         | T-050    |
| `propose_type`       | 提案         | ページに型を提案する。根拠にした本文の箇所を付けられる               | T-043    |
| `propose_property`   | 提案         | ページにプロパティの値を提案する                                     | T-043    |
| `set_property`       | 直接書き込み | プロパティを書く                                                     | T-047    |
| `create_page`        | 直接書き込み | ページを作る。型とプロパティを一緒に指定できる                       | T-047    |
| `append_to_body`     | 直接書き込み | 本文の末尾に追記する                                                 | T-048    |

## 返し方の決まり

- **漏れなく返す。** 一覧は件数で打ち切らず、ページ送りで最後まで取れるようにする。型のないページや未承認の候補がある場合は、その件数も返す。
- **提案は事実と分ける。** 未承認の提案は `pending` として別の欄で返し、承認済みのプロパティに混ぜない。
- **リンクは名前とIDの両方で返す。** エージェントが次の呼び出しに使えるようにする。
- **本文にない事実を提案させない。** 提案には、根拠にした本文の箇所を付けることを勧める。

## 記録と制限

- すべての書き込みについて、どのトークンが書いたかをサーバー側で記録する（T-038）。
- どのトークンが、いつ、どのページを読んだかを記録し、所有者が見られるようにする（T-072）。
- 利用量には課金せず、回数の上限だけを設ける。値は未決（T-073）。

## つなぎ方

MCPはAPIサーバーの `/mcp` で受けます。実装には `@modelcontextprotocol/sdk` を使う想定です（T-037で依存に足す）。
